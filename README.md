# Наша семья — фотожурнал для портфолио

**Веб-интерфейс / демонстрация.** Семейный фотожурнал с галереей и фильтрами, вымышленными героями и сгенерированными изображениями. HTML, CSS, JavaScript; без подключения личного альбома. Разработка с помощью ИИ и AI coding tools. [Другие проекты](https://github.com/trollpom/My-CRM/blob/main/docs/portfolio.md).

Демонстрационный семейный фотожурнал с вымышленными персонажами и сгенерированными изображениями.

## Состав и запуск

```text
index.html
styles.css
app.js
assets/
  favicon.svg
  music.mp3
  fonts/
  photos/              12 сгенерированных изображений WebP
README.md
image-prompts.md        Полный набор промптов
```

Статический HTML/CSS/JavaScript: без сборки и зависимостей. Откройте `index.html` или запустите `python -m http.server 8000` из корня и перейдите на `http://localhost:8000`.

Для статического хостинга команда сборки не нужна, каталог публикации — корень. Для GitHub Pages выберите `main` и `/ (root)` в настройках Pages.

## Сохранённые разделы и функции

- Знакомство с четырьмя членами семьи.
- Коллаж избранных кадров, история, шесть семейных ценностей, полный фотоальбом и финальная цитата.
- Исходный музыкальный файл, включение и пауза по явной кнопке.
- Просмотр фото в диалоге с кнопками, стрелками клавиатуры, Escape и свайпами. Фокус возвращается к выбранному кадру.
- Мобильная навигация и анимации появления. Настройка уменьшения движения отключает анимации.

## Что изменено

Редакционный дизайн семейного фотожурнала: кремовый фон, ягодные акценты, локальные шрифты, крупные заголовки, полароидные рамки и асимметричные композиции. В альбоме 12 новых изображений вместо 55 личных фотографий исходника: восемь семейных сцен и четыре портрета одной вымышленной семьи.

Добавлены фильтры: все моменты, дома, на природе, путешествия и наша команда. Счётчики отражают реальное число изображений, а просмотр внутри категории использует именно её фотографии.

Реальные имена заменены вымышленными: Александр, Мария, Алиса и София. Семья, фотографии и история обозначены как иллюстративный контент для портфолио.

## Обезличивание

Поставляемая версия не содержит исходных фотографий, `family.zip`, результатов распознавания лиц, манифестов личного альбома, ссылок на его источник или автоматического обновления из альбома. Для генерации не использованы фотографии реальных людей. Все новые изображения оптимизированы в WebP без сохранения личных EXIF.

Репозиторий `trollpom/portfolio_2` содержит только новую обезличенную версию. История исходного репозитория и прежние фотографии сюда не переносились.

## Проверка

Проверены синтаксис JavaScript, уникальность ID, ссылки, локальные файлы, SVG-иконки, отсутствие исходных фото и соответствие размеров изображений. В изолированной модели DOM проверены галерея и фильтры, счётчики, просмотр выбранной категории, переходы по кругу, одиночный кадр, клавиатура, свайп, возвращение фокуса, меню и состояния музыкального переключателя.

Полноценная визуальная проверка и воспроизведение аудио в браузере в текущей среде недоступны. Перед рекламным запуском откройте страницу на телефоне и компьютере.
